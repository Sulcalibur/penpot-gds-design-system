# Penpot GDS Design System

The **GOV.UK Design System (GDS)** rebuilt as a Penpot component library and design-token
set, pinned to [`govuk-frontend@v6.5.1`](https://github.com/alphagov/govuk-frontend/releases/tag/v6.5.1)
so every value traces back to a real release rather than a screenshot.

Components are live Penpot components with GDS's own variant axes, laid out on flex and grid.
Every colour, size and space is a token. Nothing is flattened.

## Contents

| Path | What it is |
|---|---|
| `GDS - Design System.penpot` | The Penpot file — a ZIP archive in Penpot's `export-files` v1 format |

That is the whole library. Import it into Penpot and everything below is inside.

## Opening the file

In Penpot (**Projects → Import file**) pick `GDS - Design System.penpot`. The export was
generated by **Penpot 2.18.1** and uses the `design-tokens/v1`, `variants/v1`,
`components/v2`, `layout/grid` and `fdata/path-data` feature sets.

A `.penpot` file is a ZIP archive: unzip it and you get `manifest.json`, a `files/<file-id>/`
tree with `tokens.json` and one directory per page. Handy for diffing or scripting, but Penpot
is the only sane way to view it.

## The token layer

**575 tokens across 6 sets**, in three tiers — palette primitives, functional roles, and
component-level bindings. Components bind to the functional and component tiers, so a theme
swap re-skins the library without touching a single component.

| Set | Tokens | Role |
|---|---:|---|
| `GDS/Palette` | 68 | Primitive colour, straight from `settings/_colours-palette--internal.scss` |
| `GDS/Functional` | 35 | Semantic roles (`govuk.functional.*`) — what components bind to |
| `GDS/Context` | 48 | Contextual colours (links, borders, focus, backgrounds) |
| `GDS/Typography` | 72 | Composite type styles (size + weight + line-height) and font families |
| `GDS/Component` | 43 | Component-scoped bindings |
| `MoneyHelper` | 309 | Brand override set for the MoneyHelper theme |
| **Total** | **575** | |

### Themes

Two Penpot token themes sit over the same components — switch the theme, and the components
re-brand:

| Theme | Enabled sets |
|---|---|
| `GDS / Gov UK` | the five `GDS/*` sets |
| `GDS / MoneyHelper` | the five `GDS/*` sets plus `MoneyHelper` |

### Provenance

Every token carries its origin in its `$description` — the GDS Sass variable and the file it was
read from, e.g.:

> `$govuk-palette "blue" "primary" = #1D70B8. Source: govuk-frontend@v6.5.1
> settings/_colours-palette--internal.scss. PRIMITIVE TIER — bind to a govuk.functional.* token,
> not to this.`

Where a value had to be measured rather than read from source, the deviation is recorded in the
token's description instead of being hidden.

## Components

**40 of 40 GDS components**, as real components with the variant axes GDS defines — the sidebar
shows genuine selectors like `Style=Default, State=Hover`.

Thirteen of them are **variant containers**, where Penpot derives the property dropdowns from
the children's `Property=Value` names:

| Container | Variants | Properties |
|---|---:|---|
| `Button` | 20 | `Style` × `State` |
| `Checkbox` | 16 | `Size` × `State` × `Checked` |
| `Radio` | 16 | `Size` × `State` × `Checked` |
| `Input` · `Select` · `Textarea` | 8 each | `State` × `Disabled` × `Error` |
| `List` | 6 | `Type` × `Spaced` |
| `Accordion` · `Details` · `Character count` · `File upload` · `Password input` · `Tabs` | 2 each | one property |

Alongside Button, Tag, Fieldset, Date input, Link, Radios, Summary list, Table, Error summary,
Notification banner, Pagination, Panel, Phase banner, Service navigation, Breadcrumbs, Header,
Footer, Skip link, Task list, Section break, Caption, Heading, Paragraph and the rest.

**Components are live instances.** Editing `Button` or `Footer` updates every template and
prototype that uses it.

### Layout behaviour

The rules the library is built on, if you plan to edit it:

- Every container with children carries a flex or grid layout with explicit gap, padding and alignment.
- Structural children (rules, dividers, backgrounds) **fill** horizontally.
- Content-hugging children (Tag, Button, Checkbox, Radio, Back link) are deliberately left **auto**.
- Text needs **both** `growType = auto-height` and horizontal `fill` — `auto-width` silently
  overrides fill, and `fixed` fills but clips once text wraps.
- **`addFlexLayout()` resets padding, gap and alignment to zero.** Re-assert them after any layout change.

### The rule that governs every variant set

> Every variant in a set must carry the **same child tree** — same names, same order, same
> nesting. Variants may differ in a node's *properties*; they must never differ in whether a
> node **exists**.

Breaking it does not error — it silently destroys overrides.

## Status

The library is a work in progress and not every GDS feature is represented.

- **Patterns, page templates and dark mode are out of scope.** GDS ships no dark mode.
- **GDS Transport is not bundled.** Penpot cannot register font files, so the library renders in
  **Arial** — GDS's own declared fallback, with the same two weights. Re-pointing it is a single
  token (`govuk.typography.family.base`).
- **Layout objects** (`form-group`, `button-group`, `grid-row`, `grid-column-*`, `width-container`,
  `main-wrapper`) are not yet components.
- Some component states are unbuilt, including the `--inverse` and `--inline` modifiers, and
  file-upload drag-and-drop.
